DESCRIPTION (one paragraph)

Most GPU software is written in CUDA, which runs only on NVIDIA hardware. Muse Port has an AI model (Meta's Muse Spark) plan and port real CUDA projects to SYCL, an open standard that also runs on AMD GPUs and CPUs. Nothing counts as done until a check the model never sees confirms that the port's output matches the original. Its main test case is Andrej Karpathy's llm.c: the model ported the production GPT-2 trainer (12 CUDA files, 4,884 lines) in one run, and the port passes llm.c's own test on a CPU, an NVIDIA GPU and an AMD GPU. After tuning on rented GPUs, the portable version trains at 1.40 to 1.55 times CUDA's time on two NVIDIA GPUs. Muse Port is a working research tool, built during the Meta Global AI Developer Hackathon 2026 and submitted to it. Every number comes from evidence committed in the repository, and its failures are published there too.
