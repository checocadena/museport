# Changes made to oneapi-agent-toolkit during the hackathon

The toolkit's state before the hackathon is the tag `pre_hackathon`. Every change made to it from
Oct 27 for Muse Port is listed here, with its pull request.

| Date | Change | PR |
|---|---|---|
| 2026-10-26 | Meta API details aligned with Meta's docs (`MODEL_API_KEY`, `max_completion_tokens`, `reasoning_effort`, built-in Muse prices, `Retry-After`); `ONEAPI_AGENT_AUTH_FROM_NETWORK=1` for a key injected by a proxy; `--provider baseten` for Muse Spark Open | [#19](https://github.com/checocadena/oneapi-agent-toolkit/pull/19) |
| 2026-10-26 | `gpu-test`: optional `native_flags` task field, appended to the native `nvcc` build, so CUDA that calls cuBLAS/cuBLASLt links (`-lcublas -lcublasLt`); found on llm.c's Tier 3 kernels. Merged as `7138b09` | [#20](https://github.com/checocadena/oneapi-agent-toolkit/pull/20) |
| 2026-10-27 | Agent loop: a `delete_file` tool (a file or directory under the work dir; never the work dir or `build/`) and `read_file` with an optional line range (`offset`, `limit`); both named in the system prompts. Muse runs spent one turn per SYCLomatic file overwriting it with a stub, and several ended in that clean-up with a correct port written. Merged as `e693601` | [#21](https://github.com/checocadena/oneapi-agent-toolkit/pull/21) |
| 2026-10-27 | `gpu-test` on AMD: the CUDA source's quoted local headers (and theirs, once each) are hipified too, and written next to the converted source. llm.c's `common.h` includes `<cuda_runtime.h>`, so the native build failed on a DigitalOcean MI350X and the port could only be compared with the reference. Merged as `23fdcff` | [#22](https://github.com/checocadena/oneapi-agent-toolkit/pull/22) |
| 2026-10-27 | Agent loop: `read_file` may open, by absolute path, the local headers the task's CUDA source `#include`s (recursively); other task files, which can hold the hidden reference, stay refused. museport's GPT-2 harness includes llm.c's `train_gpt2_fp32.cu`, which Muse could not read in stage 1. Merged as `f1420fc` | [#23](https://github.com/checocadena/oneapi-agent-toolkit/pull/23) |
| 2026-10-27 | GPU test bundles: a task `fetch` list (large files downloaded on the GPU machine from an `https` URL and checked against their sha256, kept out of the 50 MB bundle) and a task `gpu_setup` script (sourced on the machine before `gpu-test`, so what it exports reaches the build; its `setup.log` is archived with the results). museport's GPT-2 GPU task needs llm.c's 1 GB weights and debug state, and oneMath built with its cuBLAS backend on the NVIDIA machine. Merged as `c9c2904` | [#24](https://github.com/checocadena/oneapi-agent-toolkit/pull/24) |
| 2026-10-28 | `remote-test --public-tls` (DigitalOcean): the droplet names itself `<ip-dashes>.sslip.io`, gets a Let's Encrypt certificate with certbot and serves the agent on port 443, so a client behind an egress proxy that allows only hostnames on 443 (this cloud session) can reach it. Before this, DigitalOcean AMD runs only worked from a laptop. Merged as `41973f2` | [#25](https://github.com/checocadena/oneapi-agent-toolkit/pull/25) |
| 2026-10-28 | `gpu-test`: a `record_native` task field records the original CUDA's outputs (run twice; sha256 and run-to-run difference kept; no port built), and `reference_cmd` may name `{task_dir}`. museport's differential checks (J1) use the recording as the hidden reference. Merged as `2440918` | [#26](https://github.com/checocadena/oneapi-agent-toolkit/pull/26) |
| 2026-10-28 | `candidate_cmd` may name `{task_dir}`, as `reference_cmd` can (#26). museport's J3 trainer check runs the program through a fixed wrapper in the task dir (outside the work dir the model can edit), and gpu-test's native command, derived from `candidate_cmd`, goes through the same wrapper. Merged as `0d4a1af` | [#27](https://github.com/checocadena/oneapi-agent-toolkit/pull/27) |
| 2026-10-28 | Agent loop: an `edit_file` tool (`path`, `old_str`, `new_str`; `old_str` must appear exactly once in a file under the work dir), named in both system prompts. In J3's test port, Muse had to guard the 1,117-line trainer's `main` with `#ifndef TESTING`. Without a way to change part of a file it re-read the trainer to rewrite it and ran out of turns (run 2). With `edit_file`, run 3 made the guard in two edits and succeeded. Merged as `80f4f4f`; museport pins that commit | [#28](https://github.com/checocadena/oneapi-agent-toolkit/pull/28) |
